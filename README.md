## 发布新文章

1. 复制 `article/_template` 文件夹。
2. 将副本重命名为 `YYYY-MM-DD-英文短标题`，例如 `2026-10-08-my-first-post`。
3. 编辑文件夹里的 `index.md`，填写 `title`、`date`、`summary` 和 `tags`。`tags` 可以自由添加，例如：

   ```yaml
   tags:
     - Animation
     - Filmmaking
   ```
4. 将文章图片放在同一个文件夹，并在 Markdown 中使用相对路径，例如 `![图片说明](image-01.jpg)`。
5. 将修改提交并推送到 `main` 分支；GitHub Actions 会自动构建并发布网站。

文章会按日期从新到旧排列，每页显示 6 篇。文件夹名称不要以下划线开头，否则 Jekyll 会忽略它。
